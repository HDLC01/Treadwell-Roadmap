# About this Showcase

This is the home for the tools we've built for Treadwell — what's done, what's underway,
and what's next. Think of it as a guided tour of the work.

## How to read it

Every roadmap is shown as an **epoxy floor being installed**. It builds up the same way a
real floor does — prep the surface, prime it, lay the base coat, then the glossy topcoat —
so you can see a project go from an idea to finished and "in use."

- **Systems** are the finished tools (like the Proposal Tool and the News Feed).
- **Divisions** are the parts of the business — Operations, Finance, Sales & Marketing,
  and Admin & IT. Each one has its own floor, and every task is tagged with the division
  it belongs to, so you can follow the work by tool *or* by department.

## What the colors mean

- 🟢 **Live** — finished and in use (a glossy, cured floor).
- 🟡 **In Progress** — being worked on right now (the floor is still being poured).
- 🔵 **Planned** — lined up and ready to start (primed).
- ⚪ **Not Started** — on the list for later (bare concrete).

## Two kinds of pages

- **How-To (SOP)** — plain-English guides on using each tool. Start here.
- **Documentation** — the technical details for engineers who maintain the tools.

## The guiding idea

We pick work by payoff: things that help **sales** first, then **save cost**, then make
**admin** easier — a couple of projects at a time, each one delivering something useful
within a few weeks.
